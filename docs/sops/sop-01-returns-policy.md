# SOP-01: Returns Policy

## Returns window
Standard returns are accepted within 30 days of purchase with a receipt.
Electronics have a 14-day return window. Final-sale and clearance items are
not returnable.

## Reason codes
Cashiers must record one reason code per return: CHANGED-MIND, DEFECT,
WRONG-SIZE, WRONG-ITEM, DAMAGED, WARDROBE (item worn and returned),
NO-RECEIPT, DEFECT-FRAUD (suspected intentional damage).

## Abuse thresholds
A customer crosses the returns-abuse watch threshold at 4+ return events in
30 days, or any 2+ WARDROBE / NO-RECEIPT / DEFECT-FRAUD events in 30 days.
At 10+ suspicious events in 30 days the account is auto-flagged for the
regional loss-prevention review and further returns require manager approval.

## Refund method
Refunds go to the original payment method. No-receipt returns are capped at
$50 store credit per day.
