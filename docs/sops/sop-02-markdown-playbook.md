# SOP-02: Markdown and Promotion Playbook

## Overstock identification
A SKU is an overstock candidate when days of cover exceeds 90 at a store with
stable or declining velocity. The planner surfaces these weekly per store.

## Markdown tiers
- Cover 90-120 days: up to 15% markdown, planner may propose, store manager approves.
- Cover over 120 days: up to 30% markdown, requires regional manager approval.
- Every markdown action is gated behind human confirmation in the assistant;
  the agent never marks down autonomously.

## Promotion guardrails
Promotions must not stack with active markdowns on the same SKU. Promo
discounts above 25% need merchandising approval. Measure promotion impact by
comparing velocity during the promo window against the trailing 30-day
baseline, never against plan alone.

## Clearance
SKUs with cover above 180 days move to clearance (50%+) only after the
markdown tiers above have been attempted and documented.
